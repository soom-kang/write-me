설치 위치는 `~/.codex/skills/write-me`와 `~/.claude/skills/write-me`입니다. Codex 설치본이 이전 패키지와 일치함을 확인하고 백업한 뒤 갱신했으며, Claude Code 대상이 없음을 확인한 뒤 복사했습니다. 신규 Codex 설치 안내는 공식 경로인 `~/.agents/skills`를 사용합니다. 이 Mac에서는 중복 설치나 경로 이전을 하지 않았습니다.

Codex 선택 근거는 설치된 `SKILL.md`를 읽는 성공한 command event입니다. 작성·윤문은 마지막 완성 응답을 검토했으며, 실행 중의 진행 안내와 구분했습니다. Claude Code의 자동 선택은 `Skill` 호출과 본문 확장 event로 직접 확인했습니다. 명시 `/write-me` 호출에서는 별도 본문 확장 event가 stream에 노출되지 않았습니다. 발견·정상 종료·mode 준수와 [공식 headless 호출 계약](https://code.claude.com/docs/en/headless)을 근거로 명시 호출 성공을 기록하며, 본문 적재 event를 직접 관측한 것으로 표현하지 않습니다.

실행에는 다음 형태의 명령을 사용했습니다. 각 입력은 stdin으로 전달하고 작업 디렉터리는 프로젝트와 분리된 임시 폴더로 지정했습니다.

```sh
codex --no-daemon exec --ephemeral --sandbox read-only \
  --skip-git-repo-check --json --color never -C "$neutral_cwd" -
```

```sh
claude -p --tools Skill,Read --allowedTools 'Skill(write-me)' \
  --permission-prompts none --no-session-persistence \
  --output-format stream-json --verbose \
  --strict-mcp-config --mcp-config '{"mcpServers":{}}' \
  --settings '{"disableAllHooks":true}' --no-chrome \
  --add-dir <home>/.claude/skills/write-me
```

Claude Code에서는 쓰기 도구와 외부 MCP를 제외하고 사용자 hooks를 세션 한정으로 비활성화했습니다. 제공된 도구는 `Read`, `Skill`뿐이었고 permission denial은 없었습니다. 관리 정책의 hooks는 이 설정보다 우선할 수 있으므로 해당 옵션을 모든 환경의 완전한 격리 보장으로 해석하지 않습니다. [Claude CLI 안내](https://code.claude.com/docs/en/cli-reference)

필터링한 실행 결과와 비교 기록은 `<work_dir>`에 저장했습니다. `codex/discovery.json`, `codex/results.json`, `claude/results.json`은 발견·선택 근거와 검증용 출력만 담습니다. 전체 설정·인증 정보·일반 tool 출력은 기록하지 않았으며, 임시 기록은 배포 패키지에 포함하지 않습니다.

타이틀은 README용 자산이며 Skill 설치 폴더에는 포함하지 않습니다. 따뜻한 종이색과 먹색, 작은 교정 표시를 사용한 가로 편집 디자인입니다. 최종 파일은 `assets/write-me-title.png`이며 실제 비율은 2:1입니다. 이미지의 문구는 `Write Me`, `한국어 작성 · 윤문 · 검토` 두 개로 제한했습니다.
